
# Surplus Food Management System

## Project Overview
A web-based surplus food management system that connects bakeries and customers to reduce food wastage.

## User Roles
- Vendor (Bakery/Restaurant)
- Customer

## Main Features
- Vendor registration and login
- Upload surplus food items with images
- Customers browse available food listings
- Online payment integration
- OTP-based pickup verification
- Order management

## Technology Stack
- Frontend: HTML, CSS, JavaScript, React (planned)
- Backend: Python Django (planned)
- Database: MySQL (planned)

## Project Status
Development in progress.
